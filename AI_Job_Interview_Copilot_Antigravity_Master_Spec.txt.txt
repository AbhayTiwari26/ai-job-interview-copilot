AI JOB & INTERVIEW COPILOT
MASTER PROJECT SPECIFICATION FOR ANTIGRAVITY
=============================================

PROJECT GOAL
------------

Build a production-quality MVP called "AI Job & Interview Copilot".

The application allows a user to:

1. Register/login securely.
2. Upload a resume PDF.
3. Paste a job description.
4. Analyze the resume against the job description using Gemini through Spring AI.
5. Show an overall job-match score and detailed skill-gap analysis.
6. Generate personalized interview questions based on the user's resume and job description.
7. Conduct a text-based mock interview.
8. Evaluate the user's answers using AI and provide scores and actionable feedback.

The project must be realistic, polished, deployable, and easy for a fresher to explain in a technical interview.

CORE USER FLOW
--------------

The primary user journey should be:

1. User opens application.
2. User registers.
3. User logs in.
4. User reaches dashboard.
5. User uploads resume PDF.
6. User pastes job description.
7. User clicks "Analyze Match".
8. Backend extracts resume text.
9. Backend sends resume text + job description to Gemini using Spring AI.
10. Gemini returns structured analysis.
11. Backend validates the response.
12. Backend stores the analysis.
13. Frontend displays:
    - Overall match score
    - Matched skills
    - Missing skills
    - Skill category scores
    - Experience match
    - Keyword/ATS compatibility
    - Strengths
    - Recommendations
14. User clicks "Prepare Interview".
15. AI generates personalized interview questions.
16. User starts mock interview.
17. AI asks one question at a time.
18. User submits an answer.
19. AI evaluates the answer.
20. Frontend displays:
    - Overall score
    - Technical accuracy
    - Completeness
    - Communication feedback
    - Missing points
    - Improvement suggestions
21. User continues to the next question.

MAIN FEATURES
-------------

FEATURE 1 — USER AUTHENTICATION

Implement:

- Registration
- Login
- JWT authentication
- Logout
- Protected routes

Security requirements:

- Hash passwords using BCrypt.
- Never store plain-text passwords.
- Never expose JWT secret.
- Never expose Gemini API key to frontend.
- Protect authenticated backend endpoints.
- Validate user input.
- Configure CORS properly.
- Return appropriate HTTP status codes.

FEATURE 2 — RESUME UPLOAD

Allow the user to upload a PDF resume.

Flow:

PDF
 ↓
Spring Boot
 ↓
PDFBox
 ↓
Extract text
 ↓
Store extracted text
 ↓
Use for AI analysis

Requirements:

- Only accept PDF files.
- Limit maximum file size.
- Validate content type.
- Handle invalid PDFs.
- Handle empty PDFs.
- Handle scanned/image-only PDFs gracefully.

OCR is intentionally OUT OF SCOPE for this 2-day MVP.

If the PDF contains no extractable text, show a useful message instead of crashing.

FEATURE 3 — JOB DESCRIPTION

User should be able to paste a job description.

Store:

- Job title
- Job description
- User ID
- Creation date

FEATURE 4 — AI JOB MATCHING

This is the main feature.

Input:

Resume
+
Job Description

AI analyzes:

- Technical skills
- Experience
- Projects
- Keywords
- Responsibilities
- Qualifications

Output should include:

- Overall match score
- Matched skills
- Missing skills
- Technical score
- Experience score
- Project score
- Keyword score
- Strengths
- Recommendations

Example:

Overall Match:
87%

Technical Skills:
92%

Experience:
80%

Projects:
90%

Keywords:
85%

Matched Skills:
- Java
- Spring Boot
- React

Missing Skills:
- Docker

IMPORTANT:

The AI must NOT invent qualifications or experience.

If the resume does not mention something, treat it as unavailable rather than assuming the user has it.

FEATURE 5 — PERSONALIZED INTERVIEW QUESTIONS

Generate interview questions using:

- Resume
- Job description
- Matched skills
- Missing skills
- User projects
- Target role

Generate three categories:

1. Technical
2. Project
3. HR/Behavioral

Questions should be personalized.

Example:

If the resume contains:

"AI Expense Tracker using Spring Boot and Spring AI"

and the job description asks for:

"Java + Spring Boot + REST APIs"

the AI could generate:

"Explain the architecture of your AI Expense Tracker and why you selected Spring Boot."

Avoid generating only generic questions.

FEATURE 6 — MOCK INTERVIEW

Create a text-based mock interview.

Flow:

AI Question
    ↓
User Answer
    ↓
AI Evaluation
    ↓
Score + Feedback
    ↓
Next Question

For each answer evaluate:

- Overall score: 0-10
- Technical accuracy: 0-10
- Completeness: 0-10
- Communication: 0-10
- What was done well
- What was missing
- How to improve
- Better answer structure

Do not judge information that was not required by the question.

Do not fabricate facts about the user's experience.
